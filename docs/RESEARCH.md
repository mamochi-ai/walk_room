# 調査記録（2026-10-26）

区分：**確認済**＝公開資料で確認／**推定**＝根拠はあるが未確認／**未取得**＝確認できていない

## 開発環境の制約（重要）
開発に使ったクラウド環境のネットワーク方針では、次のホストへの通信が拒否された（HTTP 403）。
そのため、**実データの中身（建物・道路・店舗の個別の値）は開発時に取得・目視確認できていない**。

- `overpass-api.de`（OSM）
- `api.plateauview.mlit.go.jp` / `assets.cms.plateau.reearth.io` / `www.geospatial.jp`（PLATEAU）
- `www.mitsui-chintai.co.jp`（物件ページ。検索エンジンの抜粋のみ確認）

対応：アプリは**利用者のブラウザ**から公式APIへ対象範囲だけを1回取得し、端末内（IndexedDB）に30日保存する。
通信できる環境で `node tools/export-area.mjs` を実行すれば `data/area.json` として同梱でき、以後は外部APIに問い合わせない。
動作確認は、形式を再現した**テスト専用の合成データ**（`tests/fixtures/`。アプリ本体は参照しない）で行った。

## 4. 道路・店舗・駅（OpenStreetMap, ODbL）
- 取得：Overpass API（`https://overpass-api.de/api/interpreter`）に、中心から 800m の矩形で1回だけ問い合わせ。
- 歩行可能な道路：`highway=*` のうち、motorway・工事中・屋内通路・`access=private/no`・`foot=no`・`service=driveway/parking_aisle` などを除外（私有地・未確認の通路を近道にしない）。道路の幅は種別からの推定（`width` タグがあれば使用）。
- 施設：`shop=convenience`、`shop=supermarket`、`railway=station`。入口は建物の `entrance` ノード、駅は `railway=train_station_entrance`/`subway_entrance`。無い場合は「入口位置未確認」。
- 営業時間：`opening_hours` がある場合だけ「OSM登録値」として表示。
- OSM に未登録の店舗：`data/poi-supplements.json` に店舗公式情報（URL・確認日つき）で追加できる。
